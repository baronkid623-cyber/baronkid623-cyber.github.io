## 目标访问者是谁？他们最先寻找什么信息？

| 访问者 | 首要寻找的信息 |
|--------|--------------|
| 实习招聘者 / HR | 技术栈（C/C++/Python/AI）、项目经验、GitHub 链接 |
| 同学 / 项目伙伴 | 当前研究方向、技能标签、合作可能性 |
| 教师 / 导师 | 学术兴趣、竞赛经历、FinTech 方向深度 |
| 竞赛队友 | 项目经验、技术能力、联系方式 |

访问者最先看到的必须是：**一句话定位 + 技能概览 + 项目入口**。首页在 3 秒内要传达"这个人是谁、擅长什么、做过什么"。

## 本期明确不做什么？

| 项目 | 原因 |
|------|------|
| 自定义域名 | 当前 *.github.io 足够用 |
| 访客统计 / 分析 | 保护访客隐私，不嵌入第三方脚本 |
| 评论系统 | 个人站点无需评论区 |
| 多语言切换 | 中英双语已直接在页面中展示 |
| 复杂交互 / 动画 | 保持简洁学术风 |
| 电商 / 支付 | 非商业站点 |
| 博客系统 | 无持续输出内容时不做 |
| 联系方式表单 | 直接展示邮箱即可 |

## 哪些信息不能公开？

| 类别 | 原因 |
|------|------|
| 身份证号 / 学生证号 | 个人隐私 |
| 家庭 / 宿舍地址 | 个人隐私 |
| 私人手机号 | 防止骚扰 |
| 课程邀请码 | 授权限制 |
| API Key / Token / 密码 | 安全风险 |
| 未授权照片 | 肖像权 / 版权 |
